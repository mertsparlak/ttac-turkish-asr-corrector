# TTAC Technical Smoke Benchmark

This repository-safe pack contains synthetic text prompts and references for the Milestone 0 technical pilot. It is not a substitute for participant recordings and contains no personal data.

- 120 read sentences: 80 `tech_dev`, 40 `tech_test_frozen`
- 12 spontaneous prompts: 8 development, 4 frozen
- 12 term families, disjoint between read splits
- 8 frozen negative controls that contain no technical term
- Text assets are frozen before recording; any content change requires a new content version.
